# Tesla Clone 🚗

A Tesla website clone built using **React**, **Styled Components**, and **Framer Motion**.

---

live demo: https://tesla-clone-test.netlify.app/

--
## 🚀 Features
- Full-screen sections
- Smooth scroll animations
- Fade-in effects on scroll
- Responsive design

---

## 🛠️ Tech Stack
- React
- Styled Components
- Framer Motion
